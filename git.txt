Clone and run on a new machine
==============================

1) Clone repository
-------------------
git clone https://github.com/adityamadhava/arena12.git
cd arena12

# If PAT is required:
# git clone https://<GITHUB_USERNAME>:<PAT>@github.com/adityamadhava/arena12.git
# Example:
# git clone https://adityamadhava:ghp_xxxxxxxx@github.com/adityamadhava/arena12.git


2) Backend setup
----------------
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# Configure env
cp ../.env.example .env
# Edit backend/.env and fill:
# - MYSQL_DATABASE, MYSQL_USER, MYSQL_PASSWORD, MYSQL_HOST, MYSQL_PORT
# - CLERK_WEBHOOK_SECRET
# - NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY
# - CLERK_SECRET_KEY


python manage.py migrate
python manage.py import_problems ../problems/merged_problems.json


3) Frontend setup
-----------------
cd ../frontend
npm install
cp .env.local.example .env.local
# Edit frontend/.env.local and fill Clerk keys if needed


4) Run app (4 terminals)
------------------------

# Terminal A (Backend API + WebSockets)
cd arena12/backend
source .venv/bin/activate
daphne -b 127.0.0.1 -p 8000 config.asgi:application

# Terminal B (Celery worker)
cd arena12/backend
source .venv/bin/activate
celery -A config worker -l info -Q execution,events --without-heartbeat

# Terminal C (Redis)
redis-server

# Terminal D (Frontend)
cd arena12/frontend
npm run dev -- --hostname 0.0.0.0 --port 3000


5) Open app
-----------
Frontend: http://localhost:3000
Backend API: http://127.0.0.1:8000/api/problems/
